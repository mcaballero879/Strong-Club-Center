# STRONG GYM

Frontend de STRONG GYM construido con React + Vite + JavaScript + CSS.

## Requisitos

- Node.js 20+
- npm

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Backend

Copiar `.env.example` a `.env` y configurar:

```env
VITE_API_URL=http://localhost:3000/api
```

Los servicios API ya están separados en `src/services/` para conectar el backend posteriormente.
